02 · Sprite lab

One generated sheet per action, 16 frames each

Each 4×4 grid is a single Nano Banana 2 edit call that uses the character sheet as its reference. The pipeline removes the magenta background, slices the grid and aligns every frame to the first one, which removes most of the AI jitter. Every loop was checked frame by frame, and sheets with missing props, swapped hands or floating UI were regenerated. The other six characters were made by redrawing the hero's sheets with their look, so poses and timing match exactly. Pick a character to see their set.

03 · Variety

Many people from a few sheets

There are two layers of variety. Characters change the silhouette, face and clothes, and cost one sheet per animation each. Outfits are free: a small mask marks the top, hair and pants on each frame, and a palette recolors them. Skin tones come from the base bodies, because recoloring skin left speckles. The native app does this in the shader, so a new outfit needs no extra texture memory.

Procedural outfits

Every character has a clothing mask: top, hair, pants and an accent (beanie, shirt, tee). Colours come from the agent's ID like the office layout does, so the same agent always wears the same clothes and nobody in one office shares a shirt.

The cast

7 characters · 8 animations each

Each character has the full set: walking toward and away from you, idle, typing, reading, sipping coffee and both ping pong sides. Six were generated from the hero's sheets as pose guides (48 calls, $3.84). Their clothing masks came from 48 more calls ($3.84): an AI-painted colour map gives the rough regions and each pixel's own colour settles the exact edge. An office gives each agent a different character, and characters repeat in new outfits once all seven are taken.

05 · How it gets built

A single Rust binary with iced, watching your transcripts

You don't run anything per session. Claude Code already writes every session to ~/.claude/projects. The app watches those files and turns each new line into office behavior. Hooks are optional and only make events arrive faster.

Source

Claude Code sessions

Each session appends JSONL lines: prompts, tool calls, subagent tasks, results and token usage.

Watch

notify + tail

Reads only the new bytes since the last offset in each file. Each project becomes a tab, and an idle session closes its office.

Model

Event → agent state

tool_use, Task spawns and usage update a small per-session state machine. No network access.

Render

iced + wgpu shader

The crew panels, feed and tabs are iced widgets. The office is one instanced sprite pass over a single atlas, with the palette swap done in WGSL.
